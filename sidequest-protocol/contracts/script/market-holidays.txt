# Market holidays for the reference market of the equity vaults.
#
# DATA, NOT CODE, ON PURPOSE.
#
# Trading hours come from a timezone database, because DST is a rule a machine
# can derive. Market holidays are not: they are a decision by an exchange, they
# differ per market, and they move -- Good Friday follows Easter, Independence
# Day shifts when it lands on a weekend, and exchanges add one-off closures for
# national days of mourning with days of notice.
#
# So this is a file an operator maintains and reviews, not a rule buried in a
# script where being wrong looks like being absent.
#
# VERIFY THESE AGAINST THE EXCHANGE BEFORE RELYING ON THEM. They are a starting
# point, not an authority: https://www.nyse.com/markets/hours-calendars
#
# Format:  YYYY-MM-DD  name
# Blank lines and lines starting with # are ignored.
#
# HALF DAYS ARE NOT LISTED, AND CANNOT BE. StrategyExecutor.closedUntil refuses
# rebalances BEFORE a timestamp; it cannot close a market early. An exchange
# closing at 13:00 ET has to be handled by narrowing the weekly window for that
# day with setTradingWindow, or accepted as an hour of trading against a thinner
# book. Listing them here would imply a protection that does not exist.
